Bloomwarden is an original 2D arena-survivor roguelite: the last garden warden defends the garden against the Blight across 10 waves, with bosses on waves 5 and 10, 8 upgrades to choose from, healing and bomb pickups, synth sound, particles and screen shake. Play it in a desktop browser, no install needed.

## Run it

```sh
node serve.ts --port 8123
# then open http://127.0.0.1:8123/index.html
```
